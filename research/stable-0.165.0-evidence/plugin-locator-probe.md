- `WorldStateContributionInput`: dropped removed `ready_selected_capability_roots` / `executor_capability_discovery`; added `step_store` (= the turn store, as in upstream `presentation_dedup_tests.rs`).

## Failures

### plugin_packages_stay_stable_across_cache_revisions_and_resolve_the_active_snapshot

Fails at line 369, `assert_eq!(catalog_a.as_bytes(), catalog_b.as_bytes());`. The host catalog on 0.165.0 renders plugin skills as `(file: rN/<cache path>/SKILL.md)` filesystem locators that embed the cache revision directory, not as stable `(plugin package: skill://...)` locators, so the catalog changes between cache revisions.

